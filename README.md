# 🔄 Loopr

### Campus-first marketplace for students

Loopr is a campus-focused marketplace designed to make it easier for students to **buy, sell, exchange, donate, and discover useful items within their campus community**.

The goal is simple: instead of searching through random groups and chats, students can use one organized platform to find what they need and connect with other students.

**🌐 Live Demo:** [Loopr](https://loopr-tan.vercel.app/)

---

## ✨ Features

* 🛍️ **Campus Marketplace** — Browse student-listed items
* 🔎 **Search & Filtering** — Find listings using keywords, categories, condition, and transaction type
* 💰 **Buy / Sell / Exchange / Donate** — Multiple ways to transact
* ❤️ **Wishlist** — Save interesting listings
* 💬 **Messaging** — Connect with sellers
* 🏫 **Campus-focused experience** — Designed around student-to-student transactions
* 📍 **Safe Meetup Locations** — Encourage safer in-person exchanges
* 📱 **Responsive UI** — Designed for desktop and mobile
* 🤖 **AI-assisted features** — Planned for smarter listing categorization and discovery

---

## 🎯 Problem

Students frequently have items they no longer need:

* textbooks
* electronics
* calculators
* lab equipment
* furniture
* bicycles
* hostel essentials
* academic resources

At the same time, other students may be looking for exactly those items.

Existing solutions often rely on WhatsApp groups, social media, or scattered college communities, making it difficult to **search, compare, verify, and manage listings**.

### Loopr aims to solve this by creating a dedicated campus marketplace.

```text

   └── Donate

```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/omkarso464/Loopr.git
cd Loopr
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:4321
```

### 4. Create a production build

```bash
npm run build
```

### 5. Preview the production build

```bash
npm run preview
```
